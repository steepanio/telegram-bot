# Telegram Bot — Module 1  
## Bot Skeleton + Command Dispatcher (с юнит-тестами)

Этот репозиторий — **учебный проект**, цель которого научиться писать **архитектурно корректного, тестируемого Telegram-бота на Java**, приближенного к production-подходам.

Проект разбит на **чекпоинты**.  
👉 **Каждый чекпоинт = отдельный Pull Request.**

Это обязательное правило.

---

## 🎯 Цель модуля

В рамках этого модуля ты научишься:

- строить каркас Telegram-бота без жёсткой зависимости от Telegram SDK
- применять паттерн Command
- изолировать внешние библиотеки
- писать юнит-тесты с первого дня
- работать через Pull Requests и код-ревью, как в реальной команде

---

## 🔁 Правило Pull Requests (ОБЯЗАТЕЛЬНО)

- **Каждый чекпоинт выполняется в отдельной ветке**
- **Каждый чекпоинт оформляется отдельным Pull Request**
- PR считается завершённым **только после код-ревью**
- Исправления по ревью вносятся в **тот же PR**

❌ Запрещено:
- объединять несколько чекпоинтов в один PR
- пушить изменения напрямую в `main`
- писать код без тестов

---

## 🧱 Архитектурные принципы

- Telegram SDK **разрешён только в адаптере**
- Core-логика не знает ничего о Telegram
- Команды не работают напрямую с инфраструктурой
- Вся логика, которую можно протестировать — тестируется
